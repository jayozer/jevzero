YOUR MAIL, YOUR CALL

Give your inbox a fresh start.

Connect one Gmail account, import a small batch, then choose when to classify it.

  1. Create a Google Cloud Web application OAuth client and enable the Gmail API.
  2. Add http://127.0.0.1:8767/oauth/callback as an authorized redirect URI (adjust for a custom port).
  3. Put GMAIL_CLIENT_ID, GMAIL_CLIENT_SECRET, and TYPESAFE_API_KEY in the ignored .env file. Restart JevZero.
Google’s gmail.modify permission allows reading and modifying mail. This app implements only reading and reviewed label changes. Jev classification sends email text to TypeSafe. Local mail and tokens are stored on disk with owner-only permissions, without application-level encryption.

See docs/usage.md for setup, privacy, and limitations.
